# NexsOS1 active documentation

Session 1 is the only active development documentation namespace.

- `../README-LLM.md` — owner directive and persistent LLM governance.
- `session-1/README.md` — active documentation index.
- `session-1/METHODOLOGY.md` — mandatory development and verification protocol.
- `session-1/ARCHITECTURE.md` — current target ownership boundaries.
- `session-1/GPU-DEVICE-CENSUS.md` — live GPU/display/device ownership, defects and safety evidence.
- `session-1/REFERENCES.md` — approved reference corpus and rules of use.
- `session-1/PLAN.md` — ordered roadmap and bounded task gates.
- `session-1/OBJECTIVES.md` — stable objective IDs, priorities, status and acceptance gates.
- `session-1/STATE.md` — verified repository/runtime state.
- `session-1/ISSUES.md` — open failures and architectural debt.
- `session-1/VERIFICATION.md` — executed verification and evidence.
- `session-1/LEGACY-MIGRATION.md` — documentation namespace migration record.

All documentation predating Session 1 is preserved under `legacy/`. Legacy
documents are evidence and design history, not proof of current behavior. Any
legacy claim used for implementation must be rechecked against current source,
tests, build logs and runtime behavior.
