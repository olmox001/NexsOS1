# NexsOS1 active documentation

Session 2 is the active development documentation namespace. Session 1 is the
committed historical checkpoint that established the current governance,
architecture and migration baseline.

- `../README-LLM.md` — owner directive and persistent LLM governance.
- `session-2/README.md` — active Session 2 index.
- `session-2/OBJECTIVES.md` — current objective/status register.
- `session-2/STATE.md` — verified current repository/runtime state.
- `session-2/ISSUES.md` — open Session 2 debt.
- `session-2/VERIFICATION.md` — executed Session 2 gates and evidence.
- `session-1/README.md` — committed Session 1 index and inherited methodology.
- `session-1/P2P-TRANSCRIPT.md` — persistent P2P conversation through the
  Session 1 commit boundary.

All documentation predating Session 1 is preserved under `legacy/`. Legacy
documents are evidence and design history, not proof of current behavior. Any
legacy claim used for implementation must be rechecked against current source,
tests, build logs and runtime behavior.
